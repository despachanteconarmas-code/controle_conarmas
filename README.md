# Conarmas Controle de OS

Aplicação web para gestão de Ordens de Serviço (OS).

## Desenvolvimento

- Instalar dependências: `npm i`
- Rodar em desenvolvimento: `npm run dev` (http://localhost:8080)
- Build: `npm run build` e `npm run preview`

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
